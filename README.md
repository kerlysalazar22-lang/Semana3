# Comparación entre Programación Tradicional y Programación Orientada a Objetos

## Autor

Kerly Keila Salazar Franco

## Descripción

Este repositorio presenta dos soluciones desarrolladas en Python para resolver un mismo problema: el registro y la gestión básica de una mascota. El objetivo principal es comparar las características de la Programación Tradicional y la Programación Orientada a Objetos (POO), permitiendo observar las ventajas y diferencias de cada paradigma.

La versión de Programación Tradicional utiliza funciones y variables para procesar la información, mientras que la versión orientada a objetos emplea clases, atributos y métodos para organizar mejor el código y facilitar su reutilización.

## Reflexión

El desarrollo de esta práctica me permitió comprender que existen diferentes formas de resolver un mismo problema en programación. Con la Programación Tradicional aprendí a organizar el código mediante funciones, lo que resulta útil para proyectos sencillos y de poca complejidad.

Por otra parte, la Programación Orientada a Objetos me ayudó a entender cómo agrupar datos y comportamientos dentro de una clase, haciendo que el código sea más ordenado, reutilizable y fácil de mantener. Además, este paradigma facilita la ampliación de un programa cuando se requieren nuevas funcionalidades.

En conclusión, considero que ambos enfoques son importantes para la formación como programador. Sin embargo, la Programación Orientada a Objetos ofrece una estructura más eficiente para desarrollar proyectos más grandes y organizados, por lo que representa una herramienta fundamental para el desarrollo de software.
